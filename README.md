# OpenCV Image Annotation & Shapes

A Python script demonstrating basic image annotation techniques and shape-drawing operations using **OpenCV** and **NumPy**.

## 📌 Features & Demonstrated Functions
* **Text Overlay**: `cv2.putText()` to draw custom text on images.
* **Circle Creation**: `cv2.circle()` to create filled or outlined circles.
* **Ellipse Operations**: `cv2.ellipse()` for rotated arcs and ellipses.
* **Polygon Drawing**: `cv2.polylines()` using NumPy coordinate arrays to draw closed geometric shapes.
